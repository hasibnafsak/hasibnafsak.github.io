حاسب نفسك - نسخة أولية PWA

المحتويات:
- index.html: واجهة الموقع والوظائف الأولية.
- manifest.webmanifest و icon.svg: تعريف التطبيق وأيقونته.
- sw.js: تخزين ملفات الموقع مؤقتًا للعمل دون اتصال بعد أول زيارة.

للتشغيل المحلي: افتح index.html في متصفح حديث. بعض ميزات التثبيت والعمل دون اتصال تتطلب استضافة HTTPS.
للنشر المجاني: ارفع محتويات المجلد إلى استضافة صفحات ثابتة تدعم HTTPS مثل GitHub Pages.

ملاحظات النسخة:
- البيانات تحفظ محليًا في المتصفح (localStorage).
- لا يوجد تسجيل حساب أو مزامنة سحابية.
- مواقيت الصلاة والتنبيهات الفعلية، والنصوص الكاملة للأذكار، والتقارير التاريخية لم تكتمل بعد.
- لا تمسح بيانات المتصفح قبل تصدير نسخة احتياطية.
